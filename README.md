This is a React application that fetches data from the [PokeAPI] and allows users to search and filter through the first 150 Pokémon. It displays basic information such as name, image, type(s), and ID, and includes real-time filtering functionality.

 Live Demo

👉 [Live Site Link]  -  (https://searchpokemon-ten.vercel.app/)

---

## Features

-  **Search** Pokémon by name
-  **Filter** by Pokémon type (Fire, Water, Grass, etc.)
-  **Display** Pokémon cards with:
  - Name
  - Sprite image
  - Type(s)
  - ID number
-  **Responsive design**
-  **Loading**, error, and empty states handled
-  Built with **React**, **Tailwind CSS**, and **Vite**

---

## Technologies Used

- React (Functional Components + Hooks)
- Tailwind CSS
- Vite (for development and build)
- PokeAPI
- Vercel(for deployment)
